# Screenshots Guide

Tento adresář obsahuje screenshoty pro dokumentaci projektu.

## Požadované screenshoty

### 1. homepage.png
- **Co zachytit:** Přehledová stránka se seznamem všech témat
- **Rozlišení:** Minimálně 1920x1080 (desktop)
- **Poznámky:** Zobrazit grid/list témat, sidebar (pokud desktop)

### 2. topic-detail.png
- **Co zachytit:** Kompletní stránka detailu tématu
- **Rozlišení:** Minimálně 1920x1080 (desktop)
- **Poznámky:** Zobrazit všechny sekce: shrnutí, studijní materiály, audio player, kvíz/flashcards

### 3. quiz.png
- **Co zachytit:** Kvízová otázka s odpověďmi a zpětnou vazbou
- **Rozlišení:** Minimálně 1920x1080 (desktop)
- **Poznámky:** Zobrazit otázku, možnosti odpovědí, případně výsledek

### 4. flashcards.png
- **Co zachytit:** Flashcard v akci (před nebo po otočení)
- **Rozlišení:** Minimálně 1920x1080 (desktop)
- **Poznámky:** Zobrazit kartičku s otázkou nebo odpovědí

### 5. mobile.png
- **Co zachytit:** Mobilní zobrazení s otevřeným drawer menu
- **Rozlišení:** 375x667 nebo podobné (mobile viewport)
- **Poznámky:** Zobrazit mobilní navigaci, responzivní layout

## Jak pořídit screenshoty

### Chrome DevTools
1. Otevřete aplikaci v prohlížeči
2. Otevřete DevTools (F12)
3. Pro mobilní: Toggle device toolbar (Ctrl+Shift+M)
4. Nastavte požadované rozlišení
5. Použijte rozšíření pro screenshot (např. "Full Page Screen Capture")

### Nástroje
- **Chrome:** Full Page Screen Capture extension
- **Firefox:** Screenshots tool
- **Online:** Screenshot.guru, Screenshot.rocks

## Formát
- **Formát:** PNG (pro kvalitu) nebo JPG (pro velikost)
- **Optimalizace:** Použijte TinyPNG nebo podobný nástroj pro zmenšení velikosti
- **Název:** Použijte názvy uvedené výše

## Poznámky
- Odstraňte osobní údaje před publikováním
- Zajistěte konzistentní vzhled (stejný browser theme)
- Použijte reálný obsah (ne lorem ipsum)
